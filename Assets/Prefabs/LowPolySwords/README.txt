LOW POLY SWORDS - DOCUMENTATION

1. PACKAGE CONTENTS

This package contains:
- 32 low poly sword models
- Multiple material/color variants
- FBX models
- Ready-to-use Unity prefabs
- Materials

2. INSTALLATION

Import the package into your Unity project.

All assets can be found inside:
Assets/halfpucked/LowPolySwords/

3. USAGE

Open the Prefabs folder and drag the desired sword prefab
into your scene.

All prefab root transforms are configured as:

Position: 0, 0, 0
Rotation: 0, 0, 0
Scale: 1, 1, 1

4. MODEL SCALE

The models are created for standard Unity world scale.

5. REQUIREMENTS

No additional packages are required.
No scripts are included.
